## Calculator Project
##📌 Overview

This is a simple yet functional Calculator application built using Python/C (you can choose your language). It performs basic arithmetic operations and helps in understanding core programming concepts such as functions, conditional statements, and user input handling.

## 🚀 Features
Addition (+)
Subtraction (-)
Multiplication (×)
Division (÷)
Reminder (%)
User-friendly command-line interface
Continuous calculations until user exits

## 🛠️ Technologies Used
Programming Language: Python / C
Concepts: Functions, Conditionals, Loops, User Input Handling
